# laravel

Existing pages for the `laravel` fixture (ROUGHBOOK-BROWNFIELD-PLAN.md, B1), laid over it by
`conformance/run.mjs`: routes for `/`, `/about`, `/pricing`, `/blog/{post}`, `/login` and
`/account` (behind the `auth` middleware), a layout with a shared header partial and a footer
component, a marketing layout component, sections included by name, an anonymous component with
props, and atoms. Edit it by hand: no scaffold writes it.
